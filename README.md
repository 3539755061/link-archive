## 阅读版的做法

- **固定行距 1.9**，正文栏宽固定 **38em**（中文一行 34–38 字）。栏宽用 `em`，所以字号随窗口变化时每行字数不变。
- **自适应**：≥1180px 两栏（目录吸顶左侧）；窄屏目录回到顶部；<760px 手机布局（安全区、目录可滑动、回到顶部按钮）。
- 原始页面的**颜色与加粗保留**（`<span style="color:…">`、`<b>`、`<mark>`），便于快速定位重点。
- 单文件自包含，没有任何外部依赖，离线也能看。
