> *Why do we need activation functions*（5:44）

**〔00:02〕** 我们来看看为什么神经网络需要激活函数，以及如果在神经网络的每个神经元中都使用线性激活函数，它为什么就行不通。

**〔00:15〕** 回顾一下这个需求预测的例子：如果我们为这个神经网络中的所有节点都使用线性激活函数，会发生什么？结果是这个大型神经网络将变得和线性回归没什么两样。

**〔00:32〕** 这就违背了使用神经网络的初衷，因为它只能拟合我们第一门课中学过的线性回归模型，无法处理任何更复杂的情况。我们用一个更简单的例子来说明。

**〔00:49〕** 来看这个神经网络的例子。输入 x 只是一个数字，我们有一个隐藏单元，参数为 w1 和 b1，它输出 a1，这里也只是一个数字。

**〔01:08〕** 然后第二层是输出层，它也只有一个输出单元，参数为 w2 和 b2，并输出 a2，这同样只是一个数字、一个标量，也就是神经网络的输出 f(x)。

**〔01:22〕** 我们来看看，如果所有地方都使用线性激活函数，即 g(z) 等于 z，这个神经网络会怎样。

**〔01:36〕** 为了计算 a1 关于 x 的函数，神经网络会使用 a1 等于 g(w1·x + b1)；但 g(z) 等于 z，所以这就是 w1·x + b1，然后 a2 等于 w2·a1 + b2。

**〔02:01〕** 因为 g(z) 等于 z，我把 a1 的表达式代入进去，就变成了 w2(w1·x + b1) + b2，简化后得到 w2w1·x + w2b1 + b2。

**〔02:28〕** 结果是：如果我将 w 设为 w2 乘 w1，并将 b 设为后面这一堆，那么我们刚刚展示的 a2 就等于 w·x + b。a2 只是输入 x 的一个线性函数。

**〔02:53〕** 与其使用带有一个隐藏层和一个输出层的神经网络，我们还不如直接使用一个线性回归模型。如果你熟悉线性代数，这个结果源于这样一个事实：线性函数的线性函数本身还是线性函数。

**〔03:12〕** 这就是为什么在神经网络中拥有多个层，并不能让神经网络计算出更复杂的特征，或学到比线性函数更复杂的东西。

**〔03:24〕** 在一般情况下，如果你有一个像这样的多层神经网络，并且对所有隐藏层都使用线性激活函数，同时也对输出层使用线性激活函数，那么结果就是这个模型计算出的输出完全等价于线性回归。

**〔03:47〕** 输出 A4 可以表示为输入特征 X 的线性函数加 B。或者换一种情况：如果我们同样对所有隐藏层，也就是这里的三层隐藏层，使用线性激活函数，但为输出层使用逻辑激活函数。

**〔04:11〕** 那么你会发现，这个模型就等价于逻辑回归。在这种情况下，A4 可以表示为 1 / (1 + e^-(WX + B))，其中 W 和 B 是某些值。

**〔04:30〕** 这个大型神经网络能做到的，逻辑回归也都能做到。这就是为什么一条通用的经验法则是：不要在神经网络的隐藏层中使用线性激活函数。

**〔04:45〕** 事实上，我一般推荐使用 ReLU 激活函数，应该就完全够用了。这就是为什么神经网络需要在所有地方都使用线性激活函数之外的激活函数。
