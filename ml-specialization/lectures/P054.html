第 12 讲 前向传播通用实现

General implementation of forward propagation · 8:16 · 分 P 54

00:02上个视频中，你看到了如何在 Python 中实现前向传播，但那是通过为每一个神经元硬编码代码行来实现的。我们来看看在 Python 中更通用的前向传播实现。

00:17和上个视频类似，我这个视频的目标是给你展示代码，以便当你在实践实验室和选修实验室中再次看到它时，知道如何解读。

00:30在我们讲解这个例子时，不用担心要记下每一行代码，如果你能通读代码并理解它，那绝对就足够了。

00:40你可以做的是编写一个函数来实现一个全连接层，也就是神经网络中的单层。我来定义一个 Dense 函数，它接收来自上一层的激活值，以及给定层中神经元的参数 w 和 b 作为输入。

01:02用上个视频的例子，如果第一层有三个神经元，并且 w1、w2、w3 是这些，那么我们要做的就是把所有这些权重向量堆叠成一个矩阵。

01:23这将是一个 2×3 矩阵，第一列是参数 w11，第二列是参数 w12，第三列是参数 w13。

01:40类似地，如果你有参数 b11 等于 -1、b12 等于 -1 等等，那么我们将把这三个数字堆叠成一个一维数组 b，如下所示，-1、1、2。

01:58Dense 函数要做的是接收上一层的激活值作为输入，这里的 a 可以是 a0，也就是等于 x，或者是后面层的激活值，同时接收按列堆叠的 w 参数，以及堆叠成一维数组的 b 参数。

02:26这个函数将输入前一层的激活值 a，然后输出当前层的激活值。我们逐步来看实现这个的代码，这是代码。

02:42首先 units 等于 w.shape[1]，这里的 w 是一个 2×3 矩阵，所以列数是 3，这等于该层中单元的个数，这里 units 将等于 3。

03:00查看 w 的 shape，就是提取出隐藏单元数或该层单元数的一种方法。接着我们将 a 设为一个由 0 组成的数组，其元素个数与单元数相同。

03:17在这个例子中，我们需要输出三个激活值，这会将 a 初始化为一个包含 3 个 0 的数组。

03:29然后我们通过 for 循环计算 a 的第 1、2、3 个元素，这是 range(units)，即 0 到 units - 1，按 Python 惯例从 0 开始索引。

03:48这里的命令是 w 等于大写 W[:, j]，这是你在 Python 中提取矩阵第 j 列的方法。循环第 1 次，这会提取 w 的第 1 列，也就是 w11。

04:08循环第 2 次，当你计算第 2 个单元的激活值时，它会提取对应 w12 的第 2 列，以此类推，循环第 3 次也是如此。

04:21然后你用通常的公式计算 z，即参数 w 与接收到的激活值做点乘，再加上 b_j，之后计算激活值 a_j 等于 z，也就是对 z 应用 sigmoid 函数。

04:41循环 3 次，你就为激活值向量 a 计算出了所有三个值，最后你返回 a。Dense 函数的作用是输入来自前一层的激活值，并根据当前层的参数返回下一层的激活值。

05:02有了 Dense 函数，你可以把几个全连接层串接起来，实现前向传播。给定 x，计算 a1 等于 Dense(x, W1, b1)，W1、b1 是第一个隐藏层的参数，也称作权重。

05:33然后你可以计算 a2 为 Dense(a1, W2, b2)，W2、b2 是第二层的参数。接着计算 a3 和 a4，如果这是一个四层神经网络，那么最终输出 f(x) 就等于 a4。

06:01注意这里我用的是大写 W，因为按照线性代数的符号惯例，指代矩阵时用大写字母，小写则指代向量和标量。因为它是矩阵，这就是大写 W，就是这样。

06:24你现在知道如何从零开始，自己实现前向传播了，而且你将在这个视频后的实践实验室里亲自看到、运行并练习所有这些代码。
