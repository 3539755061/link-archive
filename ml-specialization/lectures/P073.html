00:00计算图是深度学习中的一个关键概念，也是像 TensorFlow 这样的编程框架自动计算神经网络倒数的原理所在。

00:12我们来看看它是如何工作的，让我通过一个小型神经网络的例子来说明计算图的概念。

00:21这个神经网络只有一层，也就是输出层，并且输出层只有一个单元。

00:31它接收输入 X，应用一个限性激活函数，然后输出激活值 A，更具体的说，它的输出是 A 等于 WX 加 B。

00:44它本质上是限性回归，但表示为一个具有一个输出单元的神经网络。

00:55给定输出后，代价函数就是1分2乘以 A，即预测值减去实际观测值 Y 的平方。

01:06对于这个小例子，我们将只有一个训练样本。

01:10其中训练样本是输入 X 等于-2，真实输出值 Y 等于2，且这个网络的参数是 W 等于2，B 等于8。

01:24那么我想做的是展示如何利用计算图逐步计算代价函数 J。

01:32先提醒一下，在学习过程中，我们习惯将代价函数 J 看作是参数 W 和 B 的函数。

01:47让我们把 J 的计算过程分解成单独的步骤。

01:53首先你有参数 W，它是代价函数 J 的一个输入。

02:03然后我们首先需要计算 W 乘以 X，让我把它叫做 C，如下所示。

02:21这个箭头上方以显示这个箭头上的输出值。

02:27下一步是计算 A，也就是 Wx 加 B。

02:32让我在这里创建另一个节点。

02:35这需要输入 B，即输入到代价函数 J 的另一个参数。

02:40而 A 等于 Wx 加 B，所以它等于 C 加 B。

02:48如果你把它们加起来，结果是4。

02:51于是，这开始构建一个计算图。

02:56在这个图中，我们计算代价函数 J 所需的步骤被分解成更小的步骤。

03:11它计算 A-Y,Y 等于2，所以4-2等于2。

03:19最后，这计代价是1-2乘以 A-Y 的平方，或者说1-2乘以 D 的平方，这恰好等于2。

03:30我们刚刚所做的，就是构建了一个计算图。

03:37这里的图不是指带有 X 和 Y 轴的图，而是计算机科学中使用的另一种意义上的图，即这是一组邮编，或者在这里是由箭头连接起来的节点。

03:52这个计算图展示了我们如何计算神经网络输出 A 的前向传播步骤，而且还进一步计算了代价函数 J 的值。

04:02现在的问题是，我们如何求 J 关于参数 W 和 B 的导数？我们接下来看看这个问题。

04:19这是上一张幻灯片中的计算图，我们已经完成了前向传播。

04:24通过计算图中从左到右的所有这些步骤，我们计算出代价函数 J 等于2。

04:31我们现在想做的是计算 J 关于 W 的导数，以及 J 关于 B 的导数。

04:43事实证明，前向传播是一个从左到右的计算，而计算导数将是一个从右到左的计算。

04:50这就是为什么它被称为反向传播，即从右向左反向进行。

04:56这张图的最后一个计算节点是这里的这个它计算 J 等于1.2的平方。

05:06反向传播的第一步会问，如果作为这个节点输入的地值发生微小变化，这的值会变化多少？具体来说，我们会问，如果地增加一点点，比如0.001，这在此例中就是我们的 Apsilon 值 J 的值将如何变化？在这种情况下，如果地从2变为2.001，那么 J 从2变为2.002，

05:38如果地增加 Apsilon,J 大约增加2乘以 Apsilon。

05:49我们得出结论，J 关于地的倒数对于这个输入到最终节点的值 d 等于2。

06:00因此，反向传播的第一步就是在这里填入数值2。

06:05这个值就是 J 关于这个输入值 d 的倒数。

06:09我们知道，如果地变化一点，J 会变化两倍那么多。

06:20因为这个倒数等于2，下一步是看前一个节点，并问，这关于 A 的倒数是多少？为了回答这个问题，我们必须问，嗯，如果 A 增加0.001，J 会如何变化？我们知道，如果 A 增加0.001，d 只是 A-y，如果 A 变成4.001，d 及 A-y 就会变成4.001-y 等于2，所以变成2.001。

06:56因此，如果 A 增加0.001，d 也增加0.001。

07:05但我们之前已经得出结论，如果 d 增加0.001，J 会增加两倍那么多。

07:14现在我们知道了，如果 A 增加0.001，d 增加0.001，那么 J 大约增加2乘以0.001。

07:26这就告诉我们，J 关于 A 的倒数也等于2。

07:30我要在那边填入这个值，这是 J 关于 A 的倒数，就像这个是 J 关于 D 的倒数一样。

07:45如果你以前上过危机分课，并且听过练试法则，你可能会意识到我刚刚做的这一步计算实际上依赖于危机分钟的练试法则。

07:56但如果你不熟悉练试法则，不用担心。

08:02你在这些视频的其余部分，不需要了解它。

08:06但如果你见过练试法则，你可能会意识到，J 关于 A 的倒数，是在问 D 随 A 变化了多少。

08:17即 D 对 A 的倒数乘以 J 对 D 的倒数。

08:25上面的这个小计算，表明 D 对 A 的偏倒数是1。

08:30我们之前展示过 J 对 D 的倒数等于2。

08:33这就是为什么 J 对 A 的倒数是1乘以2，等于2。

08:38而这正是我们得到的值。

08:43但记住哈，如果你不熟悉练试法则，不用担心。

08:47我们刚才在这里所经历的逻辑，就是为什么我们知道 J 的增加量是 A 的两倍。

08:54这就是为什么这个倒数项等于2。

08:57下一步，是继续像我们在反向传播中做的那样，从右向左进行。

09:04我们会问 C 的微小变化会导致这变化多少？我们弄清楚这个的方法是问，如果 C 增加 AppSilent0.001，A 会变化多少？A 等于 C 加 B。

09:26结果是，如果 C 最终变为-3.999，那么 A 及-3.999加8变为-4.9999，变为-4.001。

09:42如果 C 增加 AppSilent,A 也增加 AppSilent，而我们知道，如果 A 增加 AppSilent，那么由于 J 对 A 的倒数是2，我们知道这反过来会导致 J 增加2乘以 AppSilent。

10:00我们可以得出结论，如果 C 增加一点点，J 会增加两倍那么多。

10:07我们知道这一点，因为我们已经知道 J 对 A 的倒数是2，这就使我们能得出结论，J 对 C 的倒数也等于2，我将把这个值填在那里。

10:24记住，只在你熟悉练试法则的情况下，另一种写法是，J 对 C 的倒数等于 A 对 C 的倒数，结果是1乘以 J 对 A 的倒数，我们之前已经算出它等于2，这就是为什么它最终等于2。

10:47通过类似的计算，如果 B 增加0.001，那么 A 也增加0.001，J 增加2乘以0.001，这就是为什么这个倒数也等于2。

11:05我们将在这里填入 J 对 B 的倒数，以及这里 J 对 C 的倒数。

11:12最后一步，J 对 W 的倒数是多少？那么如果 W 增加0.001，会发生什么？C 是 W 乘以 X，如果 W 是2.001，C 即 W 乘以 X，变成-2乘以2.001，所以它变成-4.002，如果 W 增加 AppSilence,C 下降2乘以0.001，

11:46或者等价地说，C 增加-2乘以0.001，而我们都知道，如果 C 增加-2乘以0.001，因为 J 对 C 的倒数是2，这意味着 J 将增加-4乘以0.001，对吗？因为如果 C 增加一定量，J 就变化两倍那么多。

12:17两倍于，你知道，-2乘以这个，就是-4乘以这个。

12:24这是我们得出结论，如果 W 增加0.001，J 增加-4乘以0.001，因此 J 对 W 的倒数是-4，我将把-4写在这里，因为这是 J 对 W 的倒数。

12:45再来一次，如果你熟悉链式法则，计算过程是这样的，它是 C 对 W 的倒数乘以 J 对 C 的倒数，这个是2，这个是-2，所以我们最终得到-4，但记住，如果你不熟悉链式法则，也不用担心。

13:08总结一下，我们刚刚所做的，是在这个计算图中，手动执行反向传播。

13:15前向传播是一个从左到右的计算，我们有 W 等于2，这时我们能计算 C，然后我们有 B，这时我们能计算 A，这就是 D，然后是 J，反向传播是从右到左的，我们先计算 J 关于 D 的倒数，然后回过头，计算 J 关于 A 的倒数，接着是 J 关于 B 的倒数，

13:41J 关于 C 的倒数，最后是 J 关于 W 的倒数，这就是为什么反向传播是一个从右到左的计算，而前向传播是一个从左到右的计算，事实上，我们可以再次和对我们刚才的计算，使用这些 WBX 和外值的 J，等于2分之1乘以 WX 加 B-y 的平方，

14:13也就是2分之1乘以2乘-2-8-2的平方，结果等于2。

14:20如果 W 增加0.001，那么 J 变为2分之1乘以 W，现在是2.001乘以 X，也就是-2，加上 B-8-y 的平方，如果你把这个算出来，结果是1.996002，大致上，J 从2下降到了1.996，你知道，还有额外的002，

14:56因此，J 下降了大约4乘以 ApC，这表明，如果 W 增加 ApC,J 下降4乘以 ApC，或者等价的说，J 增加-4乘以 ApC，这就是为什么，这关于 W 的倒数是-4，也就是我们在这里算出的结果，如果你愿意，可以随时暂停视频，

15:24自己验算一下，如果另一个参数，B 增加 ApC，会发生什么？希望你能得出，这关于 B 的倒数，确实是2，即如果 B 增加 ApC,J 增加2乘以 ApC，正如这个倒数计算，所预测的，我们为什么使用反向传播算法来计算倒数呢？

15:53事实证明，反向传播是计算倒数的一种高效方式，我们将其按从右到左的顺序来计算，原因是，如果你一开始，就要问 J，关于 W 的倒数是多少？为了知道，改变 W 如何影响 J，对吧？如果 W 增加 ApC,J 会增加多少 ApC?

16:19我们首先想知道的是，J 关于 C 的倒数是多少？因为改变 W 会改变 C，即这里的这个第一个量，为了知道改变 W 如何影响 J，我们想知道改变 C 如何影响 J，但是为了知道改变 C 如何影响 J，计算这个最有用的信息是，改变 C 会改变 A,

16:46所以你想知道改变 A 如何影响 J，以此类推，这就是为什么，反向传播被安排为一个从右到左的计算，因为如果你从右到左计算，你可以先找出改变 D 如何影响 J，然后你能找出改变 A 如何影响，J 以此类推，直到你找到所有这些中间量的倒数，

17:20C,A，和 D，以及参数 W 和 B，这样你就可以通过一次从右到左的计算，改变任何这些中间量 C,A，和 D，以及输入参数 W 和 B，改变这些量中的任何一个，将如何影响最终的输出值 J，反向传播高效的一个原因是，你注意到当我们进行从右到左的计算时，

17:51我们只需计算一次这个项，即 J 对 A 的倒数，而这个量随后被用于计算 J 关于 W 的倒数和 J 关于 B 的倒数，事实证明，如果一个计算图有 N 个节点，即 N 个这样的框，以及 P 个参数，在这个例子中，我们有两个参数，这个过程允许我们大约在 N 加 P 部内，

18:24计算出这关于所有参数的所有倒数，而不是 N 乘以 P 部，如果你有一个神经网络，比如有1万个节点，和可能10万个参数，这按现代标准，甚至都不算是一个非常大的神经网络，能够在1万加10万部，即11万部内计算出倒数，

18:50远比需要1万成10万部，即10亿部要好得多得多。

18:56使用计算图完成的反向传播算法，为你提供了一种非常高效的方式，来计算出所有的倒数。

19:11这就是为什么，它是当今深度学习算法，实现中如此关键的一个思想。
